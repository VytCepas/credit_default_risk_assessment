# Semester Practical Project Specification

## Overview

The semester practical project is a team-based AI product development project where students design, implement, and manage an AI-enabled system from idea to deployment.

**Goal:** Simulate a real-world AI project lifecycle, combining:

- AI/ML development
- Software engineering practices
- Project management

**Team Structure:** Teams of 4–5 members, each developing one AI-based product/system.

---

## Project Requirements

### 1. AI-Enabled System

A functional prototype that includes:

- Data processing pipeline
- Machine learning model
- Basic interface or API

### 2. Project Management Artifacts

- Meeting minutes (weekly)
- Task tracking (Jira / GitHub / Azure DevOps)
- Sprint/iteration planning
- Risk management log

### 3. Technical Documentation

- Data preparation process
- Model development and experiments
- Evaluation metrics and results
- Deployment setup

### 4. Final Report (Term Paper)

Must include:

- Introduction and problem statement
- Business justification of the idea
- System architecture
- ML model experimentation
- Testing and validation
- Risk analysis
- Lessons learned

---

## Project Timeline & Milestones

### TA1: Problem & Feasibility — Defense 05.14

**Deliverables:**

- Project idea + business justification
- Defined problem statement
- Initial dataset exploration
- Feasibility analysis
- Initial task list (backlog)

### TA2: Model Development & Experimentation — Defense 05.21

**Deliverables:**

- Data preprocessing pipeline
- Initial ML model
- Experiment results (baseline)
- Git repository with commits
- Task tracking (Jira/GitHub)

### TA3: System Integration & Evaluation — Defense 05.28

**Deliverables:**

- Improved model (after iterations)
- System prototype (API/UI optional)
- Testing results
- Risk management report
- CI/CD or workflow setup (basic)

### Final Submission

Complete system and documentation:

- Final working prototype
- Final report (revised from TA1–TA3)
- Project presentation

## Evaluation

### Grade Formula

$$\text{Final Grade} = 0.5 \times \text{Continuous Assessment} + 0.5 \times \text{Final Project}$$

Also expressed as: $0.3 \times \text{TAs} + 0.4 \times R + 0.3 \times GKD$

### Continuous Assessment (50%)

| Milestone | Weight |
|-----------|--------|
| TA1 | 15% |
| TA2 | 15% |
| TA3 | 20% |

### Final Project (50%)

| Component | Weight |
|-----------|--------|
| Implementation quality | 20% |
| Final report | 20% |
| Presentation | 10% |
