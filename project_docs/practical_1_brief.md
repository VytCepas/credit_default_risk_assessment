## Stage 3: Event Storming

**Deadline: 05.09**

Apply Event Storming activities and get a user story map as a result.

**Recommended tools:**
- [Miro Event Storming Template](https://miro.com/miroverse/event-storming/)
- [Prooph Board](https://prooph-board.com/)

**Legend:**
| Sheet | Colour | Represents |
|-------|--------|------------|
| Actor | Yellow | Who performs the action |
| Activity / Function / Command | Blue | What is done |
| Risk / Hotspot | Red | Areas of concern |
| Opportunity | Green | Areas for improvement |

Record activity execution.

**Additional resources:**
- [EventStorming official site](https://www.eventstorming.com/)
